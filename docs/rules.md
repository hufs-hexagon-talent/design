# 화면 규칙

admin-app 과 user-app 은 같은 화면 규칙을 따른다. 값은 `src/tokens.ts` 에 있다. 부품 명세는 docs/components.md 에 있다. 규칙을 바꿀지는 담당자가 정한다.

## 짜임

- 화면은 부품으로만 짠다. 부품에 없는 모양이 필요하면 이 저장소의 값과 docs/components.md, 앱의 부품을 먼저 고친다.
- 한 화면에서 한 일을 끝낸다.
- 단계 화면, 숫자 타일, 별도 미리보기 화면, 이동 경로는 담당자가 요청할 때만 쓴다.
- 이미 있는 조작이나 이미 보이는 정보와 같은 일을 하는 요소를 더하지 않는다.
- 카드 안에 카드를 넣지 않는다.
- 새 화면과 바뀌는 화면은 견본 캡처로 담당자 확인을 받은 뒤 구현한다.

## 글자

- 누르거나 켜는 요소의 글자는 짧은 이름만 쓴다.
- 설명 문장은 화면에 두지 않는다. 꼭 필요한 설명은 제목 옆 InfoTip 에 둔다.
- 화면 글자에 시스템 용어를 쓰지 않는다. 정책, 일정, 건, 실행, 창, 동작이 여기에 든다.
- 글자 크기는 8단계(title, heading, prose, body, control, meta, label, micro)만 쓴다.
- 한국어 글자는 낱말 중간에서 줄을 바꾸지 않는다. 두 앱의 기본 글자 설정이 `word-break: keep-all` 을 건다.

## 목록, 필터, 검색

- 목록은 행마다 구분선을 긋는다.
- 결과 수, 시각, 출처 같은 보조 정보는 meta(13/18) 로 쓴다.
- 필터는 개수가 붙은 단일 선택 탭이다. 여러 개를 고르는 칩은 쓰지 않는다.
- 검색칸은 표 카드 안, 탭 아래에 둔다.
- 결과가 없으면 조건 한 문장만 적는다.

화면 표, 판의 대상 줄, 서랍 안 표, 내려받는 엑셀 파일은 모두 표의 열 순서 규칙(R1~R7)을 따른다.

| 번호 | 규칙 |
|---|---|
| R1 | 맨 왼쪽 열은 그 목록의 정렬 기준이다. 관리자는 이 값으로 행을 찾는다. |
| R2 | 행을 가리키는 열이 여럿이면 시간, 자리, 사람(이름, 학번) 순서로 둔다. |
| R3 | 상태는 행을 가리키는 열 바로 뒤에 고정 폭으로 둔다. 상태는 모든 행에서 같은 자리에 선다. 상태 열은 휴대폰 첫 화면에도 남는다. |
| R4 | 길이가 변하는 열(학생, 결과, 사유, 내용, 이메일)은 하나만 둔다. 그 열은 조작 열을 빼면 맨 뒤에 두고 남는 폭을 모두 받는다. |
| R5 | 부가 정보(처리한 관리자 등)는 그 뒤에 둔다. 조작은 맨 끝에 둔다. 조작 열에도 열 제목이나 접근 이름을 붙인다. |
| R6 | 같은 개념은 앱 전체에서 같은 열 제목을 쓴다. 예: 이용 시간, 호실, 상태, 이름, 학번. |
| R7 | 엑셀 파일은 화면 표와 같은 순서를 따른다. 화면에 없는 열은 뒤에 붙인다. |

## 버튼과 알림

- 버튼 모양은 역할로 고른다. 모양은 primary, secondary, ghost, link, danger 다섯 가지다.
- 꺼진 버튼 옆에는 이유를 한 줄 적는다.
- 알림은 상자(Notice)와 토스트 두 가지만 쓴다.

## 되돌릴 수 없는 조작

2026-10-14 에 담당자가 정했다. 되돌릴 수 없는 조작은 확인 판 하나로 확인한다.

- 미리보기가 보이는 자리(카드, 오른쪽 판)의 primary 버튼이 확인 판을 연다. 붉은 버튼은 확인 판 안에만 둔다.
- 판에는 제목, 한 줄, [취소] 와 붉은 조작 버튼만 둔다.
- 제목은 조작 이름이다. 한 줄은 '되돌릴 수 없습니다.' 다. 되돌리기를 확인하는 판은 '다시 되돌릴 수 없습니다.' 를 쓴다.
- 뒤 화면에 보이는 대상과 결과를 판에 다시 적지 않는다.
- 붉은 띠, 대상 상자, 결과 문장, 복구 문장, 버튼 위 선을 두지 않는다.
- 복구 방법처럼 꼭 필요한 설명은 화면 제목 옆 InfoTip 에 둔다.
- 판이 열린 동안 조작이 막히면 한 줄 자리에 이유를 적고 조작 버튼을 끈다.

자세한 모양과 키보드 흐름은 docs/components.md 의 ConfirmDialog 에 있다.

## 접근성

- 읽는 글자는 놓이는 면에서 대비 4.5:1 이상이다. text.disabled 는 꺼진 조작에만 쓴다.
- 휴대폰에서 누르는 면은 44px 이상이다.
- 키보드 초점은 남색 2px 테두리로 보인다. 누를 때 물결을 껐으므로 초점 테두리를 지우지 않는다.
- 아이콘만 있는 버튼에는 접근 이름을 붙인다.

## AI 티 나는 모양 금지

담당자가 2026-10-14 에 AI 티 나는 모양을 금지했다. 두 앱의 검사가 잡을 수 있는 것은 검사에 넣는다.

- 장식 아이콘. 제목, 파일 이름, 알림, 토스트, 빈 화면, 버튼 글자 앞에 아이콘을 두지 않는다. 아이콘은 아래 자리에만 쓴다. 조작이 아닌 다섯 자리(사이드바 메뉴부터 행 끝 화살표까지)는 2026-10-14 에 담당자가 남기기로 정했다.
  - 글자 대신 쓰는 조작: 닫기, 이전과 다음, 새로고침, 설명 i, 메뉴 열기, 검색어 지우기
  - 사이드바 메뉴 아이콘
  - 내보내기 버튼의 엑셀 아이콘
  - 검색칸 앞 돋보기
  - 바깥 사이트로 가는 링크 뒤의 바깥 링크 표시
  - 눌러서 상세로 가는 목록 행 끝의 오른쪽 화살표
- 알약 배지. 상태와 분류는 색 바탕 칩이 아니라 색 글자로 쓴다.
- 색 띠 알림. 알림 상자에 왼쪽 색 띠, 색 바탕, 선을 쓰지 않는다. 알림 상자는 옅은 회색 면 한 가지이고, 갈리는 것은 글자색뿐이다. 선을 두르면 입력칸처럼 보인다.
- 숫자 강조. 결과 수를 굵게, 크게, 색으로 칠하지 않는다. 숫자 타일, 단계 표시, 진행 막대를 두지 않는다.
- 효과. 그라데이션, 흐림(blur), 색 그림자, 빛 번짐, 떠오르는 hover, 누를 때 물결(MUI ripple), 꾸밈 움직임을 쓰지 않는다. 그림자는 카드와 판 두 가지뿐이다.
- 움직임. 판과 가림막이 옅어지며 나타나는 것과 서랍이 옆에서 밀려 나오는 것만 쓴다. 메뉴, 툴팁, 토스트는 커지는 움직임 없이 바로 나타나고, 탭 밑줄은 고른 탭으로 바로 옮겨 간다. 2026-10-14 에 담당자가 정했다.
- 그림. 이모지, 가짜 로고, 꾸밈 그림을 쓰지 않는다. 학생 앱의 Boo 빈 화면 그림은 담당자가 정한 것이라 남긴다.
- 겹친 면. 카드 안에 카드를 넣지 않는다.

## 앱에 두는 값

- 운영 달력 색, 서비스 상태 색, 학생 예약 칸 색은 이 저장소에 넣지 않는다. 각 앱이 자기 저장소에 둔다.
